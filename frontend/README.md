# Frontend

Esta pasta tem tudo que aparece no navegador: site publico, login, Central Operacional, estilos, imagens e PWA.

## Arquivos principais

```text
index.html      pagina principal publica
equipe.html     pagina publica da equipe
login.html      login do Google e do administrador
app.html        Central Operacional
site.js         JavaScript do site publico
app.js          JavaScript da Central Operacional
style.css       visual de todas as telas
sw.js           cache/PWA
manifest.webmanifest configuracao do app instalavel
```

## Pastas de imagens

```text
assets/         imagens principais/grandes
imgs/           logos, icones e imagens gerais
imgs/fotos/     fotos dos integrantes
```

## Quando mexer aqui

- Layout do site publico: `index.html`, `site.js`, `style.css`.
- Equipe publica: `equipe.html`, `site.js`, `style.css`.
- Central Operacional: `app.html`, `app.js`, `style.css`.
- Login: `login.html`, `app.js`, `style.css`.
- PWA/cache: `sw.js`, `manifest.webmanifest` e versoes dos arquivos nos HTML.
